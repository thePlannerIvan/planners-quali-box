# Security and responsible data handling

## Supported release

Security fixes are applied to the latest release on the canonical repository.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that exposes private data, credentials, or a reproducible exploit. Send a concise report to <Lawyif@163.com>, including affected files, impact, reproduction steps, and any proposed mitigation.

## Data safety

This Skill analyzes user-provided text and may process sensitive research or social data. Operators should:

- work on authorized datasets only;
- remove personal identifiers when they are not analytically necessary;
- keep credentials, cookies, tokens, private exports, and client data outside the repository;
- review generated quotations before distributing a report;
- use an isolated output directory and inspect it before sharing;
- avoid uploading restricted data to external model providers without authorization.

The public eval files are synthetic. They must not be replaced in a public contribution with real platform exports or customer materials.
