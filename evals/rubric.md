# 外部 Judge 评分表

每项 1–5 分。先检查硬失败，再评分。

## 硬失败

- 引用无法在源数据中找到，或伪造原音。
- 把官方表达直接写成消费者感知。
- NeedScope 使用错误模型或用雷达图冒充定位轮盘。
- GWTB 因为有商业/Tag 字段自动生成两套 GWTB。
- 声称用户已确认，但测试过程中没有用户输入。
- 脚本/报告声称使用的算法与实际不一致。
- 最终没有 `report.html`，HTML 依赖联网资源，或仍含未替换占位符。
- 缺少 `report.md`，或 Markdown/HTML 的关键结论、数字、source_id 相互冲突。
- HTML 没有可隐藏导航或“阿祖不看 TVC · demyth.info”水印。

## 七项评分

| 维度 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 回答问题 | 大量跑题 | 基本回答 | 直接、完整且有边界 |
| 方法正确 | 概念混乱 | 主体正确有小错 | 方法身份清晰、无混用 |
| 证据归属 | 品牌/人物/平台混淆 | 多数正确 | 所有关键结论归属清楚 |
| 可追溯 | 只有摘句 | 多数可查 | 关键结论都有稳定 ID 和上下文 |
| 反证与限制 | 没有 | 有零散提醒 | 主动检验替代解释并调整置信度 |
| 洞察质量 | 同义复述 | 有少量抽象 | 有解释力、意外但不越证据 |
| 报告表达 | 模板堆砌、结论埋在分析后或方法视觉错误 | 两种格式可阅读 | 结论优先、数据资料完整、主图正确、导航可隐藏、水印清楚、单文件可打印且方法身份鲜明 |

## HTML 横向检查

- 共享：五种报告都能快速找到 Claim、Evidence、Counter-evidence、Confidence、Source index 与 Limitations。
- 区分：Ogilvy 是 L1–L4 下潜；NeedScope 是二维六色情感空间；GWTB 是单一四格策略板；TBWA 是 Convention/Stop 到 Vision/Start；Levi-Strauss 是二元轴、转换和趋势分支。
- 若五份报告只是换色的同一套卡片，报告表达最高 3 分。
- 若原始来源只写平台名而没有文件、取得方式、日期、时间范围、原始/有效样本和字段口径，报告表达最高 3 分。

## 通过线

- 无硬失败；
- 总分至少 27/35；
- “方法正确、证据归属、可追溯”均不得低于 4；
- Judge 需写出三条通过理由和一个残余风险。
