# 外部 Judge 评分表

每项 1–5 分。先检查硬失败，再评分。

## 硬失败

- 引用无法在源数据中找到，或伪造原音。
- `evidence-index.json` 的 source_id、dataset_id、locator 或证据节选不能回到 `normalized-corpus.jsonl`；脱敏仅靠改写且没有可连续回查的原文。
- 把物理行、分页或视觉换行当作逻辑记录，或在原生格式可正常解析时声称数据损坏/大量记录无法恢复。
- 把官方表达直接写成消费者感知。
- 没有可验证账号/主体信息，却把语气、昵称、标签或商业风格判为已验证官方身份，并据此形成关键策略结论。
- NeedScope 使用错误模型或用雷达图冒充定位轮盘。
- GWTB 因为有商业/Tag 字段自动生成两套 GWTB。
- 没有逐层追问轨迹却把现成文本价值链写成完整 Laddering/HVM，或输出 ODI 机会分数。
- 把复购、喜欢或单次强烈表达直接算成 BRQ 六维总分或完整品牌关系。
- 没有成员—成员关系却把平铺品牌好评判为品牌社群，或把品牌活动话术当成员自发道德责任。
- 把普通隐喻编码称为 ZMET，把内容抓取称为完整网络志，或从定性文本输出 MDS/区别性资产强度。
- 没有先提交包含数据结构、推荐方法、方法步骤、预期信息与边界的 CP0 方案并取得真实确认，就开始全量编码、聚类、方法专属分析或最终报告。
- 声称用户已确认，但测试过程中没有用户输入。
- 脚本/报告声称使用的算法与实际不一致。
- 最终没有 `report.html`，HTML 依赖联网资源，或仍含未替换占位符。
- 缺少 `report.md`，或 Markdown/HTML 的关键结论、数字、source_id 相互冲突。
- HTML 没有可隐藏导航或“阿祖不看 TVC · demyth.info”水印。
- 没有运行 Skill 自带的 `validate_run.mjs`，或另写“等价”校验器绕过它。
- 互斥分类的分子合计不等于总分母，或重叠类别被写成总体构成。
- 报告出现比例/计数排序却没有 `metrics-ledger.json`，或 Markdown/HTML 中的关键数字不一致。
- 对同一 HTML 做多轮无目标视觉模型复查，或 1440×900 首屏看不到一句答案和至少三条短结论。
- `claim-ledger.json` 使用高/中/低之外的自定义置信度等级。
- 单 Agent 边界复判被写成独立编码、双盲或编码者一致性。

## 七项评分

| 维度 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 回答问题 | 大量跑题 | 基本回答 | 直接、完整且有边界 |
| 方法正确 | 概念混乱或只按方法名执行 | 主体正确有小错 | CP0 清楚解释推荐方案并取得确认；方法同时满足问题与证据适配、身份清晰无混用，证据不足时主动降级 |
| 证据归属 | 品牌/人物/平台混淆 | 多数正确 | 身份、身份置信、证据用途和用户决定分开，所有关键结论归属清楚 |
| 可追溯 | 只有摘句 | 多数可查 | 关键结论都有稳定 ID 和上下文 |
| 反证与限制 | 没有 | 有零散提醒 | 主动检验替代解释并调整置信度 |
| 洞察质量 | 同义复述 | 有少量抽象 | 有解释力、意外但不越证据 |
| 报告表达 | 模板堆砌、结论埋在分析后或方法视觉错误 | 两种格式可阅读 | 1440×900 首屏可直接看到答案和三条短结论、数据来源完整、正文证据卡留有呼吸感、主图正确、导航可隐藏、水印清楚、单文件可打印；自动检查后视觉模型目检默认不超过一次 |

## HTML 横向检查

- 共享：八种报告都能快速找到 Claim、Evidence、Counter-evidence、Confidence、Source index 与 Limitations。
- 区分：Ogilvy 是 L1–L4 下潜；NeedScope 是二维六色情感空间；GWTB 是单一四格策略板；TBWA 是 Convention/Stop 到 Vision/Start；Levi-Strauss 是二元轴、转换和趋势分支；任务与价值链是情境—Job 与 A-C-V 链；品牌关系是事件线和无总分六构面；品牌社群是成员关系和三标志。
- 若八份报告只是换色的同一套卡片，报告表达最高 3 分。
- 若原始来源只写平台名而没有文件、取得方式、日期、时间范围、原始/有效样本和字段口径，报告表达最高 3 分。
- 若首屏堆入长原音、source_id 清单、完整数据账目或多段方法推理，以致不能快速复述答案，报告表达最高 3 分。

## 通过线

- 无硬失败；
- 总分至少 27/35；
- “方法正确、证据归属、可追溯”均不得低于 4；
- Judge 需写出三条通过理由和一个残余风险。
