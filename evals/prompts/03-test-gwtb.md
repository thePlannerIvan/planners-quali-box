# Case 03 — GWTB 品牌沟通策略

使用 `planners-quali-box` 比较三个虚构运动品牌 Aster Run、Northpath 与 Kairo Running 的沟通策略：

- `evals/datasets/synthetic_gwtb_aster_official.csv`
- `evals/datasets/synthetic_gwtb_northpath_official.csv`
- `evals/datasets/synthetic_gwtb_kairo_mixed.csv`

请先判断每份数据中哪些是官方账号表达、商业合作内容或其他内容，再分别拆解三个品牌的一套 GET / WHO / TO / BY。证据不足的格子允许保留不确定，并说明还缺什么。

输出到 `evals/runs/03-gwtb/`：

- `report.md`
- `report.html`
- 词频或其他必要机械产物
- `run-notes.md`

Markdown 需完整登记三个原始文件及官方性判断依据；HTML 需结论优先、有可隐藏导航和作者水印。
