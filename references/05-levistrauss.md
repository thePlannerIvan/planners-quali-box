# Levi-Strauss 结构主义文化趋势预判

## 回答的问题

数据中哪组文化二元对立最稳定？社会如何尝试调和它？当关系发生反转、替换或重新编码时，可能出现什么趋势方向？

这是结构主义启发的趋势推演，不是用公式预测未来。结论必须写成可检验假设。

## 数据处理

先做去重、字段确认、词频、情绪线索和阅读导航。`scripts/preprocess_comments.py` 可用于大样本，但聚类只帮助找到材料，不直接生成二元对立。

需要额外保留：否定/转折句、时间与地域比较、身份边界、价值冲突、反讽、异化与“原本—现在”叙述。每条原音带稳定 `source_id`。

## 工作流

### 1. 信号提取

从原文提取价值判断、角色、物、行为、场景与转换词。不要先命名宏大趋势。

### 2. 候选二元对立

每个候选写清：A 极、B 极、各自证据、中介项、时间/地域变化、反证。常见形式如自然/人工、内/外、个体/群体，但必须来自本数据，不套预设清单。

### CP1：选择结构

只有当不同候选会导向完全不同的研究结论时，请用户选择；否则模型按 Gate 选择最稳定者，并解释取舍。

### 3. 稳定性 Gate

合格主对立必须：

- 两极都在材料中出现，而不是模型补齐；
- 至少跨两个主题或来源复现；
- 存在调和失败、边界移动或第三项；
- 能解释关键异常，且记录无法解释的反例。

未通过时只交付“候选结构诊断”，不得进入趋势公式。

### 4. 变量映射

将具体角色/物件映射到结构位置，说明映射理由与竞争解释。变量不能因为方便公式而任意互换。

### CP2：确认高风险映射

映射若高度依赖研究者判断或会改变趋势方向，呈现给用户确认；低风险映射可直接继续。

### 5. 转换推演

使用正则公式或更直观的结构转换图，明确它是思考装置：谁取代谁、哪个价值被反转、旧中介为何失效、新中介如何出现。

输出 2–3 个相互区分的趋势假设，每个包含：

- 结构变化；
- 已有端倪与 source_id；
- 触发条件；
- 可观察的未来信号；
- 反证与失效条件；
- 置信度与时间尺度。

### CP3：审视方向

用户可选择深化、合并或否决方向。若任务要求直接交付，模型保留最有证据的一主一备，并把其他方向放入附录。

## 报告表达

先用 `assets/report-template.md` 写完整 `report.md`，再使用 `assets/report-shell.html` 与 `assets/methods/levi-strauss.html` 生成 HTML。视觉是一张结构主义研究图谱：二元轴、第三项、中介转换、公式与趋势分支，不采用常规卡片仪表盘。

页面顺序：主趋势判断、行动与监测信号 → 数据资料 → 主对立 → 证据地图 → 变量与转换 → 趋势假设 → 监测指标 → 反证、来源与限制。

## Gate

- 二元对立两极均有原始材料；
- 变量映射可解释且经过竞争解释检查；
- 公式不替代证据；
- 趋势带触发条件、观测指标和失效条件；
- 推断距离越长，置信度越低。
