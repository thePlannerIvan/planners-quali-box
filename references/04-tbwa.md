# TBWA 品类颠覆机会分析

## 回答的问题

品类把哪些做法当成理所当然？消费者在哪里显露疲劳、绕行或替代渴望？品牌可以停止什么、开始什么，并保留哪条 Fine Line？

## 核心结构

```text
Convention 惯例 → Fatigue 疲劳 → Vision 愿景 → Disruption 颠覆动作
```

惯例可以来自产品、体验、沟通或商业模式。颠覆不是猎奇创意，而是用新方案解决被惯例压住的真实张力。

## 数据处理

TBWA 不默认复制 Ogilvy 的聚类。先做去重、来源和品类对象检查，再用适合数据的组合：

- 重复词组与固定句式：找被反复自然化的规则；
- 抱怨、否定、比较和“本来应该”：找疲劳；
- 反常使用、DIY、跨品类替代和低频高互动评论：找愿景萌芽；
- 官方/消费者/竞品分池阅读：区分品类话术与真实摩擦。

可用聚类辅助大样本阅读，但不得以主题份额代替惯例判断。低频异常必须进入专门样本，不因规模小被丢弃。

## 工作流

### 1. 惯例候选

开放列举候选，不设 8–12 个硬配额。每个候选包含：惯例句、惯例层级、谁在维持、至少两条证据、相反证据。

### 2. 疲劳验证

判断它是稳定惯例还是偶发抱怨：重复程度、跨来源覆盖、情绪代价、消费者绕行、替代方案。没有疲劳证据的只能叫“品类特征”。

### 3. 愿景合成

从消费者正在尝试的替代、邻近品类和未满足需要中提出愿景。愿景要解决疲劳，却不能只是把惯例反过来说。

### 4. 颠覆机会卡

每张卡包含：

- **Convention**：停止默认相信什么；
- **Tension**：谁为何付出代价；
- **Vision**：更好的新常态；
- **Stop / Start**：具体停止与开始；
- **Proof**：品牌凭什么做到；
- **Fine Line**：什么必须改变，什么品牌资产不能破坏；
- **Evidence / Counter-evidence / Confidence**。

### 5. 优先级

按张力强度、品牌资格、可执行性和差异性排序。评分必须解释，不制造虚假的精确小数。

## 报告表达

先用 `assets/report-template.md` 写完整 `report.md`，再使用 `assets/report-shell.html` 与 `assets/methods/tbwa.html` 生成 HTML。视觉采用黑黄强对照的“惯例拆除现场”：左侧 CONVENTION/STOP，右侧 VISION/START，中间展示被打破的规则和 Fine Line。

页面顺序：首要颠覆机会与行动 → 数据资料 → 品类规则墙 → 疲劳证据 → 机会卡 → 优先级 → 反证、来源与限制。

## Gate

- 惯例不是普通主题或单条抱怨；
- 疲劳有重复或跨来源证据；
- 愿景不是简单反义词；
- 每个机会有品牌资格与 Fine Line；
- 低频异常经过专门复核。
