# Stage 2：小样本校准

## 任务

在全量编码或分类前，用异质样本暴露概念边界和冲突。它不是固定数量的仪式，而是降低大规模语义误差的 Gate。

## 何时必须执行

- 需要给全量语料编码、分类、聚类后命名或映射到框架。
- 多人/多模型协作，或语料跨品牌、时期、平台、语言。
- 概念边界会直接决定统计或策略结论。

纯文本细读、样本很小且不做全量编码时，可在研究记录中说明理由后跳过。

## 动作

1. 抽取覆盖典型、高值、低信号、少数、矛盾和边界案例的校准样本。
2. 形成初版 codebook：定义、包含、排除、混淆对、证据例与反例。
3. 根据执行条件选择校准模式：
   - **单 Agent 边界复判**：暂时隐藏初判标签，第二遍只看定义与原文，复判最易混淆的边界；记录改判与仍不确定项，不声称独立编码或编码者一致性。
   - **多编码者独立编码**：两名以上执行者在看不到彼此结果时编码同一校准样本，再比较分歧；只有此模式可称独立编码，并在适用时报告一致性。
4. 修改定义并重试最不稳定的边界，直到主要分歧可解释，或明确降级为探索性分析。`calibration.md` 必须记录实际模式与参与者，不能把单 Agent 复判写成双盲或独立编码。
5. 校准新路线的关键混淆：job/solution、attribute/consequence/value、当前情绪/关系历史、共同偏好/结构化社群、字面表达/隐喻、品牌 cue/已验证区别性资产。

## Gate

- 边界案例不是被强塞进最近类别。
- 分歧被记录为定义问题、证据不足或真实多义，而非仅用多数票抹平。
- 未稳定的框架不得进入正式全量统计和确定性报告。
- 不通过强制单标签消除真实多义；辅助镜头不改变主方法的核心结论责任。
- 校准名称与实际执行强度一致；单 Agent 运行没有虚构第二编码者或 agreement。
