# Stage 3：方法专属全量分析

## 任务

在稳定研究设计上运行所选方法的完整推理链。共享的是证据纪律，不共享聚类算法、评分方式或报告隐喻。

## 动作

1. 完整读取所选主方法 Reference。仅在 CP0 已确认时读取 `references/11-auxiliary-lenses.md`；在线场域读取 `references/12-netnographic-conduct.md`。不要加载未调用的全部方法。
2. 按该方法的策略处理语料：Ogilvy 做主题与情绪深化；NeedScope 做对象相关性与情感空间编码；GWTB 做品牌/角色话语拆解；TBWA 寻找惯例、疲劳与异常；Levi-Strauss 验证二元对立和转换；消费任务与价值链建立情境、job、outcome 与有证据的 A-C-V 连接；品牌关系建立事件线与六构面证据剖面；品牌社群恢复成员关系并检查三标志。
3. 脚本负责检索、计数、抽样和机械聚合；模型负责概念合并、解释、反例与推断距离。对大语料，全量覆盖采用“一次结构处理 → 一次语义路由 → 对高相关、冲突、异常和反证深读”，不反复把整份原始语料重新读入上下文。
4. 保留低频但高解释力信号，也保留不符合主叙事的材料。
5. 低频信号升级为核心解释前，检查独立来源、跨语境复现、与主问题的相关性及竞争解释；未通过时标为假设、次级信号或监测方向。
6. 形成候选主张，不直接写最终报告。
7. 辅助镜头的发现标明它深化了哪条主方法 Claim；如果没有改变解释或验证动作，就删除该镜头结果，不为框架存在感单独成章。

## Gate

- 方法专属 Gate 已逐项检查。
- 关键数字有分母、过滤条件和生成方式。
- 核心解释不是由一个稀疏关键词或单一传播链越级支撑。
- 候选主张可被反驳，而不是把主题名称包装成洞察。
- 方法名称与实际采集/分析程序相符；没有把文本重建称为 Laddering、普通隐喻称为 ZMET、内容抓取称为网络志或候选 cue 称为已验证资产。
